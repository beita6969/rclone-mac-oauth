Privacy policy

rclone-mac is a personal OAuth client used only by its owner to run rclone against the owner's own Google Drive.

What data is accessed

With the owner's permission, rclone reads and writes files in the owner's Google Drive, and the file metadata needed to list and verify them.

How it is used

The data is used only to copy and check files between the owner's own computer and the owner's own Google Drive, at the owner's request.

Storage and sharing

No data is sent to any server other than Google's. The OAuth token is stored only on the owner's computer, in rclone's local configuration file. No data is collected, sold, or shared with third parties, and none is used for advertising.

Revoking access

Access can be revoked at any time from Google Account permissions.

Contact

Questions can be raised on this site's GitHub repository.
